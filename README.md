# 🚀 Responsive Landing Page

A modern, stylish, and fully responsive landing page built using **HTML5, CSS3, and JavaScript**. Nova features a sleek dark theme, interactive navigation, animated hero section, feature cards, and call-to-action buttons.

## ✨ Features

- 📱 **Fully Responsive Design** — Adapts to mobile, tablet, and desktop screens.
- 🧭 **Responsive Navigation Bar** — Includes a hamburger menu for smaller screens.
- 🎨 **Modern UI** — Dark background, gradient accents, and clean typography.
- ⚡ **Hero Section** — Engaging headline, description, and CTA buttons.
- 🪄 **Smooth Animations** — Floating elements, fade-in effects, and transitions.
- 🃏 **Interactive Feature Cards** — Hover effects and animated card movement.
- 📊 **Hero Statistics** — Displays sample user, satisfaction, and support statistics.
- 📩 **Call-to-Action Section** — Encourages visitors to connect.
- 📅 **Dynamic Copyright Year** — Updates automatically using JavaScript.
- ♿ **Accessibility Considerations** — Keyboard focus indicators and reduced-motion support.
- 🧩 **Separate Files** — HTML, CSS, and JavaScript are organized independently.

## 🛠️ Technologies Used

- **HTML5:** Semantic page structure and content.
- **CSS3:** Flexbox, Grid, media queries, gradients, animations, and transitions.
- **JavaScript:** DOM manipulation, event listeners, mobile menu interactions, and dynamic year updates.

## ⚙️ Installation and Setup

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.
- Optional: VS Code Live Server extension.

### Step 1: Clone the Repository

```
git clone https://github.com/your-username/responsive-landing-page.git
```

Replace `your-username` with your GitHub username.

### Step 2: Navigate to the Project Folder

```
cd responsive-landing-page
```

### Step 3: Open the Project

Open the folder in Visual Studio Code:

```
code .
```

Alternatively, open `index.html` directly in your browser.

### Step 4: Run with Live Server

If you have installed the Live Server extension:

1. Open `index.html`.
2. Right-click inside the editor.
3. Select **Open with Live Server**.

Your landing page should now open in your browser.

## 📱 Responsive Design and Testing

The page uses CSS media queries to adapt to different screen sizes.

| Device  | Test Resolution | Expected Layout                                             |
| ------- | --------------- | ----------------------------------------------------------- |
| Desktop | 1440 × 900      | Horizontal navigation, two-column hero, three feature cards |
| Tablet  | 768 × 1024      | Compact spacing and responsive sections                     |
| Mobile  | 375 × 812       | Hamburger navigation and vertically stacked content         |

These are recommended testing resolutions. Verify the layout in your browser's responsive device toolbar.

### How to Test

1. Open the website in Chrome or Edge.
2. Press `F12` to open Developer Tools.
3. Enable the device toolbar.
4. Test desktop, tablet, and mobile dimensions.
5. Check navigation, buttons, transitions, and horizontal overflow.
